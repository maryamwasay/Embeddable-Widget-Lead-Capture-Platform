# BUILDLOG

## Project

**FlyRank Backend Development Track Capstone**

Embeddable Widget & Lead-Capture Platform

---

## Objective

Build a backend platform that allows customers to create embeddable widgets and safely receive submissions from websites hosted on different origins.

---

* Designed application architecture.
* Planned database models.
* Created folder structure.
